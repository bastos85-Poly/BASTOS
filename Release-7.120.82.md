# BASTOS 7.120.82 — Nettoyeur organisé comme Kudu

La rubrique Nettoyeur présente dix vues : Système, Navigateurs, Applications, Outils d’IA, Jeux, Corbeille, Raccourcis, Environnement, Bases de données et Traces de confidentialité. La vue Système expose 98 sous-options de chemins et de types de fichiers ; chaque case restreint réellement l’analyse. Les autres familles exposent aussi leurs sous-options de caches et journaux. Recherche, sélection, tri, exclusions, aperçu des tailles, confirmation et bilan sont conservés.

Les raccourcis `.lnk` à cible locale absente sont proposés ; les cibles réseau ou sur lecteur indisponible sont conservées. Les variables PATH et dossiers de développement obsolètes sont détectés dans les réglages utilisateur et machine, revérifiés, sauvegardés, puis retirés seulement si sélectionnés. Les bases SQLite reconnues sont analysées ; celles qui possèdent un journal WAL ou SHM sont conservées. L’optimisation crée une sauvegarde SQLite, puis applique `VACUUM` et vérifie l’intégrité. Les traces privées couvrent éléments récents, listes de raccourcis, historiques de terminal et sept familles de listes du Registre Windows. Ces éléments sont décochés par défaut ; les valeurs du Registre sont sauvegardées avant effacement.

La maintenance des composants Windows, du cache Delivery Optimization et de la corbeille reste séparée. Les actions spécialisées écrivent un bilan dans le Journal de Bastos. Aucune analyse ne modifie le système ; seules les actions explicitement sélectionnées et confirmées le font.

Les règles de cache proviennent de l’observation statique du paquet Kudu 3.10.0. Le parcours et les familles reproduisent son Nettoyeur Windows, mais ce port WPF n’est pas une copie pixel par pixel ni une parité complète : les cibles de cache les plus risquées ont été écartées, la fermeture automatique des applications n’est pas ajoutée et les bases actives ne sont pas optimisées. Kudu est publié sous MIT ; le texte de licence est dans `ThirdParty/Kudu-LICENSE.txt` et son dépôt est https://github.com/AdventDevInc/kudu.

Validation locale : compilation Release ; 32 contrôles du moteur fichiers sur fixtures, 16 contrôles avancés sur fichiers et clés de Registre temporaires, 47 contrôles WPF et Journal sur fixtures. Aucun cache, raccourci, historique, base ou réglage réel du PC n’a été nettoyé pendant ces tests. Le laboratoire VM complet défini dans `Build/README-ReleaseValidation.md` n’a pas été exécuté.
